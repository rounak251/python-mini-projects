✅ Server-Client Program: Multiple Clients – Single Server (Real-Time TCP)

Transport Protocol Used: TCP (Transmission Control Protocol) – reliable, connection-oriented, suitable for real-time applications when combined with threading.

This demonstrates a classic multiple-client single-server connection model using Python sockets. The server handles any number of simultaneous clients in real-time via threads.

📋 How to Run (3 simple steps)

  1. Save the two files below as server.py and client.py
  2. Open 3 terminals/windows:
    • Terminal 1 → Run python server.py
    • Terminal 2 → Run python client.py (Client 1)
    • Terminal 3 → Run python client.py (Client 2)
  3. Type messages in any client → instantly broadcasted to ALL other clients in real-time!

Server Code (server.py)

import socket
import threading

# Configuration
HOST = '0.0.0.0'      # Listen on all interfaces
PORT = 5555            # Real-time chat port
clients = []           # List of active client sockets

def broadcast(message, sender_socket=None):
    """Send message to ALL connected clients except the sender"""
    for client in clients[:]:  # Copy list to avoid modification during iteration
        if client != sender_socket:
            try:
                client.send(message)
            except:
                # Client disconnected unexpectedly
                clients.remove(client)

def handle_client(client_socket, addr):
    """Handle messages from one client in its own thread (real-time)"""
    print(f"[+] New client connected: {addr}")
    while True:
        try:
            message = client_socket.recv(1024)
            if not message:
                break  # Client disconnected cleanly
            # Prefix with sender address for clarity
            formatted = f"[{addr[0]}:{addr[1]}] {message.decode('utf-8')}\n".encode()
            broadcast(formatted, client_socket)
        except:
            break
    
    # Cleanup on disconnect
    if client_socket in clients:
        clients.remove(client_socket)
    client_socket.close()
    print(f"[-] Client disconnected: {addr}")

# ==================== MAIN SERVER ====================
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server.bind((HOST, PORT))
server.listen(100)  # Can accept up to 100 pending connections

print(f"🚀 Real-Time TCP Server started on {HOST}:{PORT}")
print("Waiting for multiple clients to connect...\n")

while True:
    client_socket, addr = server.accept()
    clients.append(client_socket)
    
    # Each client gets its own thread → true concurrency & real-time handling
    thread = threading.Thread(target=handle_client, args=(client_socket, addr))
    thread.daemon = True
    thread.start()

Client Code (client.py)

import socket
import threading
import sys

# Configuration (must match server)
HOST = '127.0.0.1'  # Change to server's IP if running on different machine
PORT = 5555

def receive_messages(client_socket):
    """Thread that continuously listens for broadcast messages"""
    while True:
        try:
            message = client_socket.recv(1024)
            if not message:
                break
            print(message.decode('utf-8'), end='')
        except:
            break

# ==================== MAIN CLIENT ====================
client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

try:
    client_socket.connect((HOST, PORT))
    print("✅ Connected to Real-Time Server! Type messages below.\n")
except:
    print("❌ Could not connect to server. Make sure server.py is running.")
    sys.exit(1)

# Start background thread for receiving messages (real-time)
receive_thread = threading.Thread(target=receive_messages, args=(client_socket,))
receive_thread.daemon = True
receive_thread.start()

# Main loop for sending messages
try:
    while True:
        message = input("")
        if message.lower() in ['exit', 'quit']:
            break
        if message.strip():  # Only send non-empty messages
            client_socket.send(message.encode('utf-8'))
except KeyboardInterrupt:
    print("\n👋 Disconnecting...")
except:
    pass
finally:
    client_socket.close()
    print("Client closed.")

🎯 Features Demonstrated

  • ✅ Single server handling multiple simultaneous TCP connections
  • ✅ Real-time message broadcasting (zero noticeable delay)
  • ✅ Threaded architecture for concurrent client handling
  • ✅ Graceful client disconnect detection
  • ✅ TCP as the transport protocol (reliable, ordered delivery)
  • ✅ Works on localhost or across network (just change HOST)

Why TCP for real-time? It provides guaranteed delivery with low latency when using lightweight threading – perfect for chat, gaming commands, live updates, etc.
